# nagato-auto-fill — 長門市しごとセンター 使用許可申請フォーム自動入力

長門市しごとセンターの施設予約（Googleフォーム「しごとセンター 使用許可申請」）を、
ポップアップで日付とテンプレを選ぶだけで自動入力するChrome拡張。**送信ボタンだけは自分で押す**。

## 使い方

1. `config.sample.js` を `config.js` にコピーし、実値（団体名・住所・氏名・電話・メール）を記入する。
   `config.js` は個人情報を含むためコミットしない。
2. `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを指定。
   （config.js や本体を更新したら「再読み込み」ボタンを押す）
3. 申請フォームを開き、拡張アイコン → 種別・日付を選んで「自動入力実行」。
   - **1ページ目（メール+同意）から実行してよい**。同意→「次へ」→2ページ目の入力まで自動で進む（v3.1）。
4. 内容を目視確認して**「送信」を自分で押す**。
5. 受付控えメール（件名「フォームにご記入いただきありがとうございます: 長門市しごとセンター【使用許可申請】」）の着信を確認する。

## フォームの仕様と落とし穴（2026-08-03 実地検証で確定）

- **2ページ構成**: 1ページ目=メールアドレス＋利用目的の同意 →「次へ」→ 2ページ目=申請本体。
- **reCAPTCHA付き**: 送信データに `g-recaptcha-response` が必須のため、**ブラウザ外からの直接POST（スクリプト送信）は成立しない**（400が返る）。ブラウザで送信ボタンを押すのが唯一の経路。これがこの拡張が最適解である理由。
- **Googleログイン中は「下書き」がアカウント単位で1つ共有される**: 複数タブで別の日付を並行準備すると、後から編集したタブの内容が下書きを上書きし、送信時に混線する。**必ず1件ずつ「入力→送信」を完結させる**こと。途中で「以前の下書きを使用しますか？」と聞かれたら内容をよく確認する（不要なら「フォームをクリア」でやり直すのが安全）。
- **このフォームは仮予約**: 送信後の自動返信（受付控え）とは別に、NPO法人つなぐからの「受付完了」メールで予約確定（対応1日以上・火曜日を挟むと2日以上）。
- 休館日: 毎週火曜と12/29〜1/3。開館は10時〜22時。
- 予約時間は準備・片付け込みで申請する運用（**イベント時間の前後30分**。例: 18:00-20:30の講座 → 17:30-21:00）。
- 減免申請「あり」で申請するため、セミナールームの有料講座（入場料の徴収=有り）でも利用料は4倍にならない。
- もくもく会は施設利用申請そのものが不要（2026-08-03 確認）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3マニフェスト |
| `popup.html` / `popup.js` | 日付・時刻・テンプレ選択UI。テンプレの既定時刻を自動セット |
| `content.js` | 入力エンジン（FormEngine）。ラベル部分一致でDOMを埋める。2ページ自動遷移対応 |
| `config.sample.js` | 設定サンプル（構造の正）。実値は `config.js`（コミットしない） |
